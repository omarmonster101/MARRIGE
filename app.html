9) سيناريوهات تشغيل مختصرة (User Flows)

  1. تسجيل عضو جديد: حساب → تفعيل SMS/Email → إكمال ملف → مراجعة صورة → ظهور في البحث.
  2. تسجيل عبر ولي: ربط ولي + موافقة مولية → ضبط صلاحيات التحكم → بدء التصفح والتواصل.
  3. اهتمام ومحادثة: إرسال اهتمام → قبول متبادل → بدء chat (مع ولي عند الحاجة).
  4. بلاغ: إبلاغ عن إساءة → مراجعة الإدارة → إجراء (تحذير/حظر) → إشعار للمبلّغ.
  5. ترقية اشتراك: تجاوز حد مجاني → دفع آمن → تفعيل المزايا فورًا.
