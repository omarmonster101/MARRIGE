# ميثاق - واجهة عربية متكاملة لمنصة زواج إسلامي

هذا المشروع يقدم **واجهة Frontend (RTL)** بتصميم حديث ومتناسق كنموذج عملي لمنصة زواج إسلامي تحترم:

- الخصوصية وحماية معلومات الأعضاء.
- القيم الشرعية في التواصل والاختيار.
- دور الولي/الوصي في إدارة التواصل.
- التحقق متعدد المراحل للحسابات.
- التشغيل عبر لوحات: مستخدم، ولي، وإدارة.

## الصفحات

- `index.html` — صفحة رئيسية تسويقية متكاملة.
- `about.html` — من نحن والرؤية والقيم.
- `privacy.html` — سياسة الخصوصية وحقوق المستخدم.
- `terms.html` — شروط الاستخدام والسلوك المقبول.
- `contact.html` — نموذج الدعم والتواصل.
- `blog.html` — محتوى إرشادي للمقبلين على الزواج.
- `faq.html` — الأسئلة الشائعة.
- `app.html` — النموذج التشغيلي الكامل (Registration/Profile/Search/Dashboard/Guardian/Admin/Pricing/Security).

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح:

- `http://localhost:4173/index.html`
- `http://localhost:4173/app.html`

## ملاحظة

هذه نسخة واجهة (UI Prototype) بدون ربط Backend فعلي. يمكن توصيلها لاحقًا مع API للمصادقة، البحث، الرسائل، الدفع، والتحقق.
